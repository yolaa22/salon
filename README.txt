YOLA BEAUTY SALON - WEBSITE LENGKAP

TEKNOLOGI:
- PHP Native
- MySQL
- HTML/CSS/JavaScript
- Responsive

CARA MENJALANKAN:
1. Install XAMPP atau Laragon.
2. Copy folder "salon_makeup" ke:
   Laragon: C:\laragon\www\
   XAMPP: C:\xampp\htdocs\
3. Jalankan Apache dan MySQL.
4. Buka phpMyAdmin.
5. Import file database.sql.
6. Buka:
   http://localhost/salon_makeup/

ADMIN:
URL: http://localhost/salon_makeup/admin/login.php
Username: admin
Password: password

CATATAN:
Password admin pada database.sql menggunakan hash bcrypt untuk password "password".
Ganti password admin sebelum website dipakai sungguhan.
